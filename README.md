# CLI To-Do App with File Saving 📝

A simple **Command Line Interface (CLI) To-Do App** written in Python.  
Add, view, mark as done, and delete tasks. All tasks are saved to a file so your list persists even after closing the app.  

---

## Features

- ✅ Add new tasks  
- ✅ View all tasks with status (done/not done)  
- ✅ Mark tasks as done  
- ✅ Delete tasks  
- ✅ Persistent storage using `tasks.txt`
